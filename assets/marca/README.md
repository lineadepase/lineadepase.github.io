# Marca procedente de las intros del autor

El usuario facilitó las cuatro intros de Línea de Pase y autorizó extraer su logo y usar las intros el 27/11/2026.

- `logo-intro.webp`: fotograma de la intro corta horizontal en 3,3 s, recorte del logo con el futbolista y el nombre. Se conserva el fondo original. No se redibuja ni se reconstruye con IA.
- `intro-poster.webp`: fotograma completo de esa misma intro para la vista previa del vídeo.
- `intro-corta-horizontal.mp4`: versión para web a 1280 px de ancho, H.264/AAC y faststart.
- `intro-corta-vertical.mp4`: versión para web a 720 px de ancho, H.264/AAC y faststart.

Los originales permanecen intactos. Las versiones cortas mantienen su duración aproximada de 3,87 s. No se usan las intros largas de 8,07 s en la página para evitar duplicar contenidos. La reproducción es opcional, con controles y sin precarga del vídeo.
